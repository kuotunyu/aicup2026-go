## 2. 方法

### 2.1 合併公式（沿用 02／03 的校準，只多加幾項）

p = softmax( e^a · (n/12)^γ · ( m_C5 + w_op·m_OP + Σ_j w_j·E_j + b ) )

- **既有的兩項**：m_C5 是 R20 的整盤 CNN（prereg02 epoch 9，8 種對稱）做 log 合併的結果；m_OP 是開局項（M＝12、α＝20，用已 commit 的 `opening_inner.npz`／`opening_val.npz`）。
- **新的項**：E_j 是新來源 j 在這一題上「每盤可解析的棋算 log_softmax(該盤 10 維向量)」的平均；一盤都沒有就記 0。
  - 每盤先加總再取 log_softmax。在 softmax 裡，這和「中心化加總」等價，所以只登記這一種形式，不另列 N1／N2。
- **盤數**：只經由共用溫度 (n/12)^γ 進來，E_j 都是平均，不是加總。
- **參數範圍**：
  - 界限：a (−4, 4)、γ (−1, 2)、所有 w (0, 4)。
  - 起點：a 取 0 和 1 兩個；其他從 0 開始。
  - PENALTY 0.01‖b‖²，MAXITER 500。
  - 5 折、假題輪次、規則 B 都和 `tools/p02_rank_fuse.py:121-129` 相同。

### 2.2 來源 O4：CPU 對手落子統計（照 scratch `B_proxy` 原樣凍結）

- **定義**：
  - 每一手都從輪到下的那一方看棋盤，每個空點編成一個格子，共 557,928 種。格子由這幾項組成：
    - 3×3 鄰域，8 種對稱正規化後 1,107 類。
    - 戰術碼：能提子、救被叫吃的子、叫吃。
    - 和對方上一手的距離（7 級）、和自己上一手的距離（3 級）。
    - 手數階段：<30、<100、其餘。
  - 比率：r_k(c) = (C_k(c)+20)/(A_k(c)+20/r(c))，α＝20。
  - 每一手：log P_k = log r_k(下的格子) − log Σ_空點 r_k。
  - 每盤：把**對手**每一手加總，得到 10 維向量。
  - 計數只用 `load_rows(part="fit")`：720,307 盤、對手 79,985,352 手，表上的等級標目標玩家的等級。交件模型是甲。
  - 重播整份 SGF，不受 250 個盤面的窗口限制。
- **證據**（inner 5 折 OOF，127,200 題，規則 B）：
  - R20＋O4：0.5855 → 0.6042，**+0.0188 [+0.0081, +0.0288]**，每題平均 +0.0190。
  - 單色假題（120,544 題）：+0.0182 [+0.0130, +0.0234]。
  - 雜訊對照組最多 +0.0006。
  - 同一套配方只看**目標方**的手，權重被擬合成 0，差值 +0.0000。
- **挑選的自由度**：O4 是事前主變體（只看目標方，失敗了）的鏡像。對手方實際只比了 3 種，全部變體加起來 9 個以上。

### 3.4 本機判定（`tools/p04_rank_fuse.py pilot`）

- **評估範圍**：`pseudo_inner.json` 的擬合輪（25,400 題）和評估輪（127,200 題）。5 折、規則 B，Q02 的各項來源全部用已 commit 的版本。

**bug 地板**（任一條不過就停下查 bug，不算判定）：
1. 局面數完全相符。
2. 真實等級頭的 top-1 準確率：目標方、對手方都 ≥ 30%。推估正常應在 38–45%。
3. 對手手的逐手 10 級交叉熵 < ln10＝2.3026。
4. MVo 單獨（只加校準）的 OOF 分等級平均 ≥ 0.40。對照：CPU 對手代理單獨是 0.5050。
5. 評估輪混色題上 κ(MVt) − κ(MVo) > 0；角色接反時會變成負的。

**判定**：
- 定義 Δ_p＝OOF 分等級平均(Q03p) − OOF(Q02)，Q03p 是 Q02 加上試跑的 MVo、MVt。
- **Δ_p ≥ +0.002，而且每步 s ≤ 200 ms**（這樣正式訓練至少有 4 輪）→ 繼續，跑正式訓練。
- 否則 MV 關閉，Q03 從清單拿掉，04 用 Q00–Q02 往下做。
- 「5 折權重都 > 0」只記錄，不當判定條件。評審實測時，雜訊、A0、B0、C6A 疊上去，5 折權重也全是正的，沒有鑑別力。
- SW 萬一在 check 被拿掉（預期不會），試跑的比較基準改成 Q01，門檻不變。

**這個門檻分不分得開**（實測加推估）：
- 已知沒用的來源疊在 Q02 上：雜訊 +0.0004、目標方 −0.0000、A0 −0.0001、C6A −0.0005，PlayerBootstrap SE ≤ 0.0013。+0.002 和它們分得開，推估誤判繼續的機率 < 10%。
- 訊號強度減半的 O 疊在 SW 上 +0.0049（會判繼續）；減到四分之一只有 +0.0010（不會）。
- 要照實寫：試跑只擋得住 bug，只放行明顯有用的模型；「完整訓練後才有用」的中間情況可能會漏掉。

**只記錄**：
- 各級差值（特別是 1D–3D）和各盤數的差值。
- 每題平均差、5 折的權重。

### 步數規則（寫死，只看速度，不看結果）
