# prereg32 試跑結果：set 模型的 weight decay × 訓練長度 → **NO-GO**

2026-11-11 判一次（`p32_pilot.py judge`，`pilot.json` 原樣 commit）。只看 S25 留出的 748 位玩家的留出 NLL，不碰 inner、不碰驗證集答案。**競賽二最終仍是 25。**

## 白話結論

加大 weight decay、拉長訓練，留出 NLL 全部比現行設定（wd 0.01、15,000 步）差，沒有「越練越好」或頓悟的跡象。wd 越大越差，拉長步數也救不回來。這題的 set 模型缺的是玩家人數，不是訓練方式。
