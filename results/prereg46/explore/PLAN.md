# prereg46 PLAN：競賽一新題加「對手指紋」項（先於任何 prereg46 分數）

日期 2026-11-15 晚（prereg45 不用之後）。分支 `p46-opp`。只做競賽一；不碰驗證集答案資料夾（不開、不讀、不列、不雜湊），
不讀 `data/prereg10/val`，不跑 `tools/score.py`，不用打分機會，不用競賽二的任何特徵或輸出。

## 0. 白話版

v2-6 的每一項都只看「目標玩家自己的手」。線上對局常和同一批對手反覆下，所以題目棋局的**對手**和候選人棋局的對手
若像是同一個人，候選人就更可能是答案。prereg39 抽的 P1 塊本來就存了兩方（`sides`＝target、opponent，`means[:, 1]`），
D、E、pub2、priv2 全都有，所以這一輪**不抽新東西、不用 GPU**，只在 CPU 上加一個分項。

## 1. 分項 T_O

- 每盤對手向量：P1 塊 `means[:, 1]`（770 維；`counts[:, 1]` = 0 或 failed 的盤不用），用 **v2-6 的 P1 投影**
  （prereg39／43 的 L-LDA64：同一個標準化＋LDA）投到 64 維，再做 v2-6 的 P1 項同樣的池內 b4 白化（以該池候選庫的
  **對手**向量、候選 id 當類別估類內共變異；若程式上不可行就不白化，兩者都列為變體），最後 L2。
- 題目 q、候選 c 的對手相似度（兩種聚合，都是變體）：
  - `max`：q 的每盤對手 × c 的每盤對手，餘弦取最大；
  - `mmax`：q 的每盤對手先對 c 的各盤取最大，再對 q 的盤平均。
- 每題對全部候選做 z 分數（`p06_style.zscore_rows`）；題目沒有可用盤 → 該列 z＝0；候選沒有可用盤 → 該欄填該列其他候選的最小值。

## 2. 融合與挑選（D 池，10 池，種子 100–109）

- 基底＝v2-6（`results/prereg43/explore/tune.json`；CNN＝prereg43 c*、後端、P1 項 wP 8、CSLS 20）：基底做 CSLS 之前的融合分數
  F_base 不動。M46＝CSLS_k(F_base ＋ wO·z(T_O))。
- 格點：白化 ∈ {b4, none} × 聚合 ∈ {max, mmax} × wO ∈ {0.25, 0.5, 1, 2, 4, 8} × k ∈ {10, 20, 40}；取 D 平均最高
  （格點順序第一個最大值）。
- 接縫：wO＝0、k＝20 時，D 每池要和 prereg43 `tune.json` 的 R（0.7467766213119217）逐位元相同，E 每池要和
  `results/prereg43/explore/eval.json` 的 c_star 逐位元相同。
- **D 閘門**：D(M46) − 0.7467766213119217 ≥ +0.01 才進 E；否則只記錄。`tune.json` 先 commit 才載入 E 池。
- 只記錄（不影響選擇）：最佳設定下 T_O 單獨使用時的 D 分數。
