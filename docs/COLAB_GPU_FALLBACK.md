# 演練（A100、H100，拿得到再加 G4；一種 GPU 跑一次，每次約 1 小時，其中 40–60 分鐘是等）

第一次照下面 A–C 全部做。之後換另一種 GPU 時，只做「再演練另一種 GPU」那一段（不用再上傳）。三種的結果放在雲端硬碟不同的資料夾，互不影響。

## 開始前（檢查 3 件事）

1. 瀏覽器開 https://drive.google.com ，右上角頭像是**平常跑 C10 Colab、雲端硬碟裡有 `C10` 資料夾的那個帳號**。
2. 左下角的儲存空間還剩至少 **2 GB**（套件 0.33 GB，結果約 0.1–0.3 GB）。
3. 電腦上打開放好檔案的資料夾：在 PowerShell 貼這一行
   ```powershell
   explorer.exe "D:\AI-Portfolio\competitions\aicup2026-go\data\test11\upload"
   ```
   裡面要**正好 3 個檔**：`C10_gpu_kit_v1.zip`（約 330 MB）、`C10_gpu_input_rehearsal.zip`、`gpu_fallback.ipynb`。不是 3 個就停下來告訴 Claude。

## A. 上傳（3 個檔）

4. 在雲端硬碟點左邊「我的雲端硬碟」→ 點兩下打開 `C10` 資料夾。
5. 左上「新增」→「新資料夾」→ 名稱打 `gpu_fallback` →「建立」。點兩下打開它（畫面上方路徑要是「我的雲端硬碟 > C10 > gpu_fallback」）。
6. 把第 3 步那個視窗裡的 **3 個檔**一起選起來，拖到雲端硬碟右邊清單的空白處放開。等右下角 3 個都打勾（套件比較大，約幾分鐘）。**傳完前不要關分頁，也不要拖第二次。**
7. **截一張圖給 Claude**：`C10 > gpu_fallback` 的畫面，要看得到 3 個檔名，而且**沒有**名字帶 ` (1)` 的檔。等 Claude 回「OK」再往下做。

## B. 開 notebook、選 GPU、開跑

8. 在 `gpu_fallback` 資料夾裡，對 `gpu_fallback.ipynb` 按右鍵 →「開啟工具」→「Google Colaboratory」。
9. Colab 上方選單「執行階段」→「變更執行階段類型」（英文介面：Runtime → Change runtime type）→ 硬體加速器選 **A100 GPU**（第一次；之後依序 H100、G4，或 Claude 指定的型號）→「儲存」（Save）。
   - **A100 有兩種**：40 GB（`A100-SXM4-40GB`）和 80 GB（`A100-SXM4-80GB`），對工具來說是兩種不同的 GPU。第 1 格的 `GPU:` 那一行會寫是哪一種。Colab 兩種都給得出來（例如選單裡有「A100」和「A100 高 RAM／80GB」）就兩種都演練；只給一種就演練那一種，回報時說是哪一種。
   - 這一種選不到：直接跳到下一種，告訴 Claude 哪一種選不到。
10. 「執行階段」→「全部執行」（Runtime → Run all）。
    - 跳出「警告：這個筆記本並非由 Google 建立」：按「**仍要執行**」。
    - 跳出要不要允許存取 Google 雲端硬碟：按「連線至 Google 雲端硬碟」，選同一個帳號，一路按「繼續」／「允許」。
11. 第 1 格印出 `GPU: ...`、`套件 OK` 和 `輸入： rehearsal ...`，第 2 格印出 `環境 OK`，第 3 格印出 `結果會寫到： .../out/rehearsal_<GPU 型號>`，第 4 格開始一行一行出現 `"chunk done"`。看到第一行 `chunk done` 就可以先去做別的事。**不要關這個分頁**。

**回報**：第 1 格的 `GPU:` 那一行，和第 4 格第一行 `chunk done` 的截圖。

## C. 等它跑完、下載

12. 第 4 格會依序算 `hs seam`、`hs offgrid`、`p1 seam`、`p1 offgrid`，每一行的 `eta_min` 是這一組還要幾分鐘。全部算完，第 5 格印出 `完成： ... C10_gpu_results_rehearsal_<GPU 型號>.zip ... sha256 ...`。
13. 回到雲端硬碟的 `C10 > gpu_fallback`，對那個 `C10_gpu_results_rehearsal_<GPU 型號>.zip` 按右鍵 →「下載」。它會存到電腦的「下載」資料夾。
14. 回到 Colab：「執行階段」→「中斷連線並刪除執行階段」（Runtime → Disconnect and delete runtime）→ 確認。
15. **雲端硬碟裡的 `gpu_fallback` 資料夾整個留著，什麼都不要刪**（測試日還要用裡面的套件和 notebook）。

**回報**：第 5 格 `完成：` 那一行的截圖（含 sha256），以及「已下載、已刪執行階段」。Claude 會從「下載」資料夾拿檔、比對數字，告訴你這種 GPU 能不能用。

## 再演練另一種 GPU（H100、G4）

16. 雲端硬碟什麼都不用動（不用把上一次的輸出移走：每種 GPU 會寫到自己的 `out/rehearsal_<GPU 型號>` 資料夾和自己的結果 zip）。
17. 照第 8–14 步再做一次，第 9 步改選這一次的 GPU。第 3 格印出的 `結果會寫到：` 要是新的型號；如果印出的是上一次的型號，表示 GPU 沒換成功，先停下來。
18. 三種都做完（或確定選不到）之後，Claude 會告訴你哪幾種准用。演練必須在 **11/04 11:00 以前**全部做完、由 Claude commit，才算數。

## 出狀況時

- 某一格出現紅字或 `STOP:` 開頭的訊息：截最後 20 行給 Claude，不要自己重跑。
- 斷線（畫面出現「已中斷連線」）：重新整理頁面 → 同一個 GPU 型號 →「全部執行」。它會從沒算完的那一塊接著算（已算好的存在雲端硬碟）。**不要換另一種 GPU 續跑**；拿不到同一種就停下來告訴 Claude。
  - 斷線時正在算的那一塊沒有存完：雲端硬碟裡可能留下名字有 `.tmp` 的檔。**不用管它、不要刪**，續跑時會被覆蓋；結果 zip 和 Claude 的工具都會忽略 `.tmp` 檔。
- 第 4 格印出 `STOP: 執行環境和這一段第一次開跑時不同`：表示換了 GPU 或版本（GPU、torch、cuDNN、Python、numpy 任一個），停下來截圖給 Claude。

# 測試日（只在 Claude 說 4090 不能用時）

Claude 會先說明是 07（hs）還是 08（p1），以及要用哪一種 GPU（一定是演練過、判定可以用的那一種）。

## 開始前

1. 雲端硬碟、帳號同演練。`C10 > gpu_fallback` 裡應該還有演練留下的檔。
2. PowerShell 貼這一行打開資料夾：
   ```powershell
   explorer.exe "D:\AI-Portfolio\competitions\aicup2026-go\data\test11\upload"
   ```
   裡面要有一個新的輸入檔，名字是 Claude 說的那一個（例如 `C10_gpu_input_hs_test.zip`）。

## A. 換輸入檔（一次只做一件）

3. 在 `C10 > gpu_fallback` 裡：左上「新增」→「新資料夾」→ 名稱 `old` →「建立」（已經有 `old` 就跳過）。
4. 把 `gpu_fallback` 裡**舊的** `C10_gpu_input_*.zip`（例如 `C10_gpu_input_rehearsal.zip`）拖進 `old` 資料夾。其他檔（套件、notebook、`out` 資料夾、舊的結果 zip）不要動。
5. **截圖給 Claude**：`gpu_fallback` 的畫面。等 Claude 回 OK。
6. 把第 2 步視窗裡那個新的輸入檔拖到 `gpu_fallback` 的空白處，等它打勾。
7. **再截一張圖給 Claude**：`gpu_fallback` 裡要正好一個 `C10_gpu_input_*.zip`（新的那個），沒有 ` (1)`。等 Claude 回 OK。

## B. 開跑

8. 同演練第 8–10 步，GPU 選 **Claude 指定的型號**（一定是演練准用的那幾種之一）。按「全部執行」之後**先看第 1、2 格**：
   - 第 1 格的 `GPU:` 要是 Claude 指定的型號，`輸入：` 要是 Claude 說的那一個（例如 `hs_test real`）。不對：馬上按「執行階段」→「中斷執行」（Runtime → Interrupt execution），截圖給 Claude。
   - 第 2 格印出 `STOP: 這個 GPU／版本 ... 不在演練准用名單`：這時還沒有算任何東西、**不算一次嘗試**。「執行階段」→「中斷連線並刪除執行階段」，換 Claude 指定的 GPU 再全部執行；拿不到就截圖給 Claude。
   - 第 2 格印出 `環境 OK ... （准用）` 才會開始算。
   - 07（hs）約 3–4 小時、08（p1）約 1 小時（演練後 Claude 會更新）。電腦和分頁都開著。

## C. 下載

9. 第 5 格印出 `完成： ... C10_gpu_results_<名稱>.zip`，照演練第 13–14 步下載、刪執行階段。雲端硬碟的檔一樣都留著。

**回報**：第 5 格 `完成：` 那一行的截圖，以及「已下載、已刪執行階段」。

## 出狀況時

- 同演練。另外：**只准一次 Colab 嘗試**（第 4 格開始算第一塊就算一次）。開始算之後斷線，續跑一定要選**同一種** GPU；拿不到同一種，或第 4 格印出 `STOP: 執行環境和這一段第一次開跑時不同`，停下來告訴 Claude，不要自己換。

## 不要做的事

- 不要改 notebook 的任何一格。
- 不要在雲端硬碟裡改名、刪除 `gpu_fallback` 裡的檔或 `out` 資料夾。
- 不要把這些檔上傳到 AIdea。這裡算出來的只是中間結果；要上傳的交件檔，Claude 會另外照原本的流程請你確認。
